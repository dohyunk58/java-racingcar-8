# java-racingcar-precourse

## 기능 목록

1. 입력 기능
- [ ] 자동차 이름을 쉼표 기준으로 입력받기
- [ ] 경주 횟수 입력받기

2. 예외 처리

- [x] 자동차 이름이 5자를 초과하거나 공백 혹은 null인 경우
- [x] 경주 횟수에 정수가 아닌 값을 입력한 경우
- [x] 경주 횟수에 양의 정수가 아닌 값을 입력한 경우

3. 메인 로직

- [ ] 입력받은 자동차 이름으로 자동차 객체 목록 생성
- [x] 무작위 값이 4 이상인 경우 자동차를 전진시키기
- [x] 입력된 횟수만큼 자동차 경주를 실행하기
- [x] 최종 우승자 결정하기(가장 먼 위치의 자동차를 찾아내기)

4. 출력 기능

- [ ] 횟수별 자동차의 이름과 이동한 거리를 출력하기
- [ ] 최종 우승자 출력하기(공동 우승 시 쉼표로 구분)
